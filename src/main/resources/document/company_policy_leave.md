# 公司请假制度

## 一、请假类型

### 1. 年假
- 员工入职满一年后可享受年假
- 工作满1年不满10年：5天/年
- 工作满10年不满20年：10天/年
- 工作满20年以上：15天/年
- 年假需提前7天申请

### 2. 病假
- 病假需提供医院证明
- 每月可享受2天无薪病假（无需证明）
- 超过2天需提供医院诊断书

### 3. 事假
- 事假无薪
- 单次事假不得超过3天
- 全年事假累计不得超过15天

### 4. 婚假
- 法定婚假：3天
- 晚婚假（男25岁以上，女23岁以上）：额外增加7天
- 需提前15天申请

### 5. 产假
- 女职工产假：98天
- 难产增加：15天
- 多胞胎每多一胎：增加15天
- 男方陪产假：15天

## 二、请假流程

1. 在OA系统提交请假申请
2. 直属领导审批
3. 人事部门备案
4. 请假期间工作交接

## 三、注意事项

- 未提前申请视为旷工
- 旷工一天扣除当日工资的200%
- 连续旷工3天以上视为自动离职
